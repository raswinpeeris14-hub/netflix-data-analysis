# Netflix Data Analysis Using Python 📊

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on Netflix movies and TV shows using Python. The goal is to clean the dataset, explore its key characteristics, and identify patterns in Netflix's content library through data analysis and visualization.

The project uses Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn to inspect the data, handle missing values, and create visualizations that help understand the distribution of movies and TV shows, contributing countries, content ratings, and genres.

## 🎯 Project Objectives

The main objectives of this project are:

- Understand the structure and characteristics of the Netflix dataset.
- Identify and handle missing values.
- Prepare a cleaned dataset for analysis.
- Compare the distribution of Movies and TV Shows.
- Examine content distribution by release year.
- Identify the countries contributing the most content.
- Explore common content ratings and their potential target audiences.
- Analyze the monthly distribution of content added to Netflix.
- Identify the five most frequently listed genres.

## 🧹 Data Cleaning and Preparation

The notebook performs the following data-cleaning operations:

1. **Importing libraries**  
   Imports NumPy, Pandas, Matplotlib, and Seaborn.

2. **Loading the dataset**  
   Reads `netflix_titles.csv` into a Pandas DataFrame.

3. **Initial data inspection**  
   Examines dataset information, dimensions, descriptive statistics, and missing values.

4. **Date-based feature extraction**  
   Derives the year, month name, and day name from `date_added`.

5. **Handling missing values**  
   Removes rows with missing values in `cast`, `director`, and `duration`.

6. **Filling missing categorical values**  
   Replaces missing country values with `"unknown"` and missing ratings with the most frequent rating.

7. **Checking data quality**  
   Rechecks missing values and inspects the dataset shape after cleaning.

8. **Exporting the cleaned dataset**  
   Saves the cleaned data to `netflix_titles_cleaned.csv` for subsequent analysis.

**Data-cleaning note:** Removing rows with missing cast, director, or duration values can exclude otherwise useful titles. The effects of these choices should be considered when interpreting the results.

## 📈 Exploratory Data Analysis

The notebook investigates six main questions.

### 1. Movies vs. TV Shows

Compares the number of Movies and TV Shows in the dataset using a count plot.

**Objective:** Understand the composition of Netflix's catalog.

### 2. Content Distribution by Release Year

Examines Movies and TV Shows released from 2012 onward, using a release-year comparison.

**Objective:** Explore how the mix of content types varies across release years.

*Note: The notebook filters from 2012 onward; it does not automatically guarantee that exactly ten years of data are included.*

### 3. Top Contributing Countries

Visualizes the ten most frequently occurring country values.

**Objective:** Identify countries that appear most often in the dataset.

*Note: If a title lists multiple countries in a single cell, the notebook counts the combined country string as one value unless the data is split into individual countries.*

### 4. Common Content Ratings

Displays the five most common ratings individually and groups the remaining ratings into an "Others" category.

**Objective:** Understand the distribution of content ratings and discuss potential audience suitability.

### 5. Monthly Content Additions

Uses the month extracted from `date_added` to compare the number of titles added in each month.

**Objective:** Explore monthly patterns in the dates Netflix titles were added.

### 6. Top Five Genres

Splits the `listed_in` column into individual genre labels and counts their frequency.

**Objective:** Identify the five most frequently listed genres in the dataset.

*Note: Genre counts represent category occurrences, not necessarily unique titles.*

## ⚙️ Installation and Setup

Install the following before running the project:

- Python 3.9 or later recommended.
- Jupyter Notebook or JupyterLab.
- The required Python libraries.
- The input dataset, `netflix_titles.csv`.

### Step 1: Clone the Repository

Replace `YOUR-USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR-USERNAME/netflix-data-analysis.git
cd netflix-data-analysis
```

### Step 2: Create a Virtual Environment (Recommended)

**Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate
```

```bash
python3 -m venv .venv
source .venv/bin/activate
```

```bash

```

### Step 4: Add the Dataset

Place `netflix_titles.csv` in the project root directory, alongside `netflix_analysis.ipynb`.

The filename must match the name used in the notebook.

### Step 5: Launch Jupyter Notebook

```bash

```

Open `netflix_analysis.ipynb` in the browser.

### Step 6: Run the Notebook

Execute the cells in order, from top to bottom. The notebook will inspect and clean the data, create `netflix_titles_cleaned.csv`, and generate the visualizations.

## ⚠️ Limitations and Considerations

- Results depend on the version and completeness of the input dataset.
- Removing rows with missing cast, director, or duration values may introduce selection bias.
- Missing ratings are filled using the mode, which may influence rating counts.
- Country values may contain multiple countries in one field.
- Release year and date added represent different concepts and should not be interpreted interchangeably.
- The date column must be converted to a datetime type before extracting year, month, or day values.
- Genre counts can include multiple category occurrences for a single title.
